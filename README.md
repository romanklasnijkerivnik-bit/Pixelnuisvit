
# 🎮 GIMP: Місія — врятувати піксельний світ

Інтерактивний навчальний вебквест з інформатики для учнів 6 класу за темою:

**§ 1. Растрова графіка. Графічний редактор GIMP**

## 📚 Про проєкт

Навчальний вебквест створений для закріплення знань учнів про растрову графіку, пікселі та можливості графічного редактора GIMP.

За сюжетом гри у цифровому світі сталася катастрофа. Учням необхідно пройти п'ять тематичних станцій, виконати завдання та відновити піксельний світ.

## 🎯 Мета

- Закріпити знання про растрову графіку.
- Ознайомити з поняттям пікселя.
- Розглянути особливості растрових зображень.
- Повторити призначення та інструменти GIMP.
- Навчитися розрізняти графічні формати файлів.
- Розвивати логічне мислення та цифрову компетентність.

## 🧩 Структура квесту

Квест складається з п'яти станцій:

1. **Піксельна лабораторія** — поняття комп'ютерної графіки та пікселя.
2. **Таємниця зображення** — властивості растрової графіки.
3. **Штаб GIMP** — призначення та інтерфейс графічного редактора.
4. **Майстерня кадрування** — інструменти та основні операції.
5. **Файловий портал** — формати PNG, JPG, XCF.

## 🚀 Як запустити

### Локальний запуск

1. Завантажити файл `index.html`.
2. Відкрити його подвійним натисканням.
3. Квест запуститься у веббраузері.

### Публікація на GitHub Pages

1. Створити репозиторій на GitHub.
2. Додати файл `index.html`.
3. Відкрити **Settings → Pages**.
4. У розділі Build and deployment вибрати:
   - Source: Deploy from a branch;
   - Branch: main;
   - Folder: / (root).
5. Натиснути Save.

Після публікації квест буде доступний за адресою:

`https://USERNAME.github.io/gimp-quest-6-class/`

Замість `USERNAME` потрібно вказати свій логін GitHub.
